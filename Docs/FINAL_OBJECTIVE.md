# SmartexVR++ — Final Project Objective
> Saved: 2026-04-15

## Vision
A multi-user industrial platform combining a 3D Desktop Digital Twin and mobile AR,
connected to live IoT telemetry (InfluxDB / MQTT), driven by the IEIA LLM agent,
and designed for the Moroccan textile sector's CBAM compliance needs.

## Core Pillars
1. **3D Desktop Twin** — real-time factory supervision (built ✓)
2. **Mobile AR** — AR Foundation, QR machine recognition, on-site data overlay
3. **Asymmetric Multiplayer** — Netcode for GameObjects (AR technician + Desktop supervisor)
4. **Embodied IEIA Agent** — LLM drone/avatar, voice queries (Whisper STT), proactive alerts
5. **Immersive Analytics** — Data Mode, temporal scrubber, correlation graph, Compute Shaders
6. **Maintenance Workflow** — step-by-step AR guide, operator behavior logging, adaptive training
7. **Training Module** — AR onboarding, kinematic cognitive load proxy, multilingual

## Scientific Contributions
- Asymmetric interfaces for industrial crisis management
- Spatially embodied LLM agents — effect on operator trust
- Kinematic proxies for cognitive load without biometric sensors
- Immersive analytics vs 2D dashboards for anomaly detection
- CBAM traceability via AR scan in MENA textile sector
